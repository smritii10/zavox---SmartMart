# RetailIQ — Store Manager Dashboard

A modern, responsive front-end prototype for a Retail Intelligence / Store Manager system.

## Sections
- Overview
- Shopper Analytics
- Footfall Intelligence
- Smart Inventory Monitoring
- Intelligent Queue Management
- Staff Management
- Reports
- AI-Driven Recommendations

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For the best development experience, open the folder in VS Code and use Live Server.

## Notes
This is a front-end prototype. The charts currently use demo data and the buttons show UI feedback. Connect the interface to your Python/OpenCV/YOLO backend through REST APIs or WebSockets to make the dashboard live.
